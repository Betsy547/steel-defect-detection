# NEU-DET 数据集说明

东北大学（Northeastern University）热轧钢带表面缺陷数据集，检测任务常用基准。

```
NEU-DET/
├── images/
│   ├── train/    1437 张
│   ├── val/       180 张
│   └── test/      180 张
└── labels/
    ├── train/    与图像同名的 YOLO 格式 txt
    ├── val/
    └── test/
```

- 图像：200 × 200 灰度图（单通道，存储为 jpg）
- 标注：每行 `类别 中心x 中心y 宽 高`，坐标已归一化到 0~1
- 总量：1797 张图，4177 个标注框

类别编号：

| id | 英文 | 中文 |
|---|---|---|
| 0 | crazing | 龟裂 |
| 1 | inclusion | 夹杂 |
| 2 | patches | 斑块 |
| 3 | pitted_surface | 麻点 |
| 4 | rolled-in_scale | 氧化铁皮压入 |
| 5 | scratches | 划痕 |

原始数据是 Pascal VOC 的 XML 标注，本项目已转换成 YOLO 格式并保持官方划分，
转换脚本见 `01_程序源码/steel-defect-yolo/scripts/import_neu_det.py`。

使用训练脚本时用 `--data-root` 指向本目录即可，不需要改 `data.yaml`：

```bash
python scripts/train.py --data-root ../../03_数据集/NEU-DET
```
