# 模型权重说明

| 文件 | 是什么 | 大小 | 用途 |
|---|---|---|---|
| `best.pt` | **YOLO11s 在 NEU-DET 上训练 150 轮的最佳权重** | 19 MB | 系统实际使用的模型 |
| `yolo11s.pt` | YOLO11s 的 COCO 预训练权重 | 19 MB | 重新训练时的起点 |
| `yolo26s.pt` | YOLO26s 的 COCO 预训练权重 | 20 MB | 对比实验 |
| `yolov8s.pt` | YOLOv8s 的 COCO 预训练权重 | 22 MB | 对比实验 |

- 只有 `best.pt` 能直接做 6 类缺陷检测，其余三个是通用预训练权重，
  直接推理只会输出 COCO 的 80 类。
- 用 `best.pt` 启动系统：

```bash
python app.py
```

不指定时程序会自动找到本目录的 `best.pt`；换目录后可以用
`python app.py --weights 路径/best.pt` 显式指定。

- 想验证权重是否完整：

```bash
python -c "from ultralytics import YOLO; m=YOLO('best.pt'); print(m.names)"
```

应该输出 6 类：crazing / inclusion / patches / pitted_surface / rolled-in_scale / scratches。
