# 模型权重说明

| 文件 | 是什么 | 大小 | 用途 |
|---|---|---|---|
| `best.pt` | **YOLO26s 在 NEU-DET 上的训练权重**（本机 RTX 4060 Laptop，第 83 轮最佳，第 113 轮早停） | 20 MB | 系统实际使用的模型 |
| `best_yolo11s.pt` | 旧版部署权重：YOLO11s（云端 RTX 4090，150 轮） | 19 MB | 仅作留档；`python app.py --weights 02_模型权重/best_yolo11s.pt` 可切回 |
| `yolo26s.pt` | YOLO26s 的 COCO 预训练权重 | 20 MB | 重新训练的起点 |
| `yolo11s.pt` | YOLO11s 的 COCO 预训练权重 | 19 MB | 对比实验 |
| `yolov8s.pt` | YOLOv8s 的 COCO 预训练权重 | 22 MB | 对比实验 |

只有 `best.pt` 和 `best_yolo11s.pt` 能直接做 6 类缺陷检测，其余三个是通用预训练权重，
直接推理只会输出 COCO 的 80 类。

## 用 `best.pt` 启动系统

```bash
python app.py
```

不指定时程序会自动找到本目录的 `best.pt`；换目录后可以用
`python app.py --weights 路径/best.pt` 显式指定。
有 NVIDIA 显卡时默认用 GPU 推理，否则自动退回 CPU；要强制 CPU 加 `--device cpu`。

## 验证权重

```bash
python -c "from ultralytics import YOLO; m=YOLO('best.pt'); print(m.names)"
```

应该输出 6 类：crazing / inclusion / patches / pitted_surface / rolled-in_scale / scratches。

这个权重的训练日志、曲线和逐轮指标在 `04_训练结果/yolo26s_deploy_train/`，
测试集指标在 `04_训练结果/test_set_metrics.json`。
