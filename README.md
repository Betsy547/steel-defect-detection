# 工业钢板表面缺陷检测系统

计算机视觉课程设计 —— 基于 YOLO 的热轧钢带表面缺陷检测。

上传一张钢板图像，系统自动检测 6 类表面缺陷并给出「合格 / 建议复检 / 不合格」判定，
同时提供批量检测、历史记录、统计看板、检测报告和开放接口。

| 项目 | 内容 |
|---|---|
| 数据集 | NEU-DET（东北大学热轧钢带表面缺陷数据集） |
| 模型 | YOLO11s，NEU-DET 微调，输入 320×320 |
| 测试集 mAP50 | **0.739**（部署批次，mAP50-95 0.427） |
| 3 seed 均值 | **0.744 ± 0.004**（mAP50-95 0.430 ± 0.003） |
| 训练环境 | AutoDL RTX 4090，150 epochs，约 7 分钟 |
| 部署环境 | 本地 CPU，单张推理约 27 ms（Ryzen 9 8945H 实测） |
| 系统形态 | Flask + 原生 HTML/CSS/JS 单页前端 + SQLite + JSON 接口 |

## 快速开始（只看系统）

需要 Python 3.10+，先装依赖：

```bash
pip install flask ultralytics opencv-python
```

在本目录启动：

```bash
python app.py
```

浏览器打开 http://localhost:5000 。

> 不指定 `--weights` 时会自动找权重：环境变量 `STEEL_WEIGHTS` → 本目录 `02_模型权重/`
> → `D:/yolo/weights/`。换机器或换目录后如果提示找不到，
> 用 `python app.py --weights 路径/best.pt` 显式指定即可。详见 [系统说明.md](系统说明.md)。

## 系统功能

界面是原生 HTML + CSS + JS 的单页应用，数据全部由 `/api/*` 提供。

| 页面 | 路径 | 说明 |
|---|---|---|
| 单张检测 | `/` | 上传图像，出判定 + 标注图 + 缺陷明细表 |
| 批量检测 | `/` 送检面板切到「批量」 | 一次最多 20 张，汇总合格率 |
| 检测历史 | `/#/history` | 所有记录入库，按判定/文件名筛选，可回看 |
| 统计看板 | `/#/stats` | 合格率、近 7 天趋势、缺陷类型分布、判定占比 |
| 模型信息 | `/#/model` | 训练指标、每类 P/R、模型对比 |
| 检测报告 | `/report/<id>` | A4 版式，浏览器直接打印成 PDF |
| 接口 | `POST /api/predict` | 返回 JSON，可被产线程序调用 |

判定规则：

| 条件 | 结论 |
|---|---|
| 没有检出缺陷 | 合格 |
| 最高置信度 ≥ 不合格阈值（默认 0.60） | 不合格 |
| 有检出但低于阈值 | 建议复检 |

## 复现训练

数据集放在 `03_数据集/NEU-DET`，类别配置是工程根目录的 `data.yaml`：

```bash
cd 01_程序源码/steel-defect-yolo
python scripts/train.py --data data.yaml --data-root ../../03_数据集/NEU-DET \
  --model ../../02_模型权重/yolo11s.pt --epochs 150 --batch 32 --imgsz 320 --cache
```

测试集评估：

```bash
python scripts/val.py --weights ../../02_模型权重/best.pt \
  --data-root ../../03_数据集/NEU-DET --split test
```

3 模型 × 3 seed 重复实验与鲁棒性压力测试在 AutoDL 上执行，命令和参数见
[cloud/README.md](01_程序源码/steel-defect-yolo/cloud/README.md)：

```bash
bash cloud/seed_sweep.sh
bash cloud/robustness.sh
```

## 实验结果

### 三模型单次对比（部署批次）

三个模型用同一套超参对比，完整数据见 `04_训练结果/comparison.md`。

| 模型 | 参数量 | mAP50 | mAP50-95 | Precision | Recall |
|---|---:|---:|---:|---:|---:|
| YOLOv8s | 11.14 M | 0.768 | 0.429 | 0.718 | 0.735 |
| **YOLO11s** | **9.43 M** | 0.739 | 0.427 | 0.709 | 0.718 |
| YOLO26s | 9.95 M | 0.758 | 0.436 | 0.755 | 0.703 |

单看这一批，差距只有 1~3 个百分点，和单次训练的随机波动是同一量级，不能据此断言模型优劣。

### 3 模型 × 3 随机种子

为区分模型差异与训练随机性，按同一协议用 seed 0/1/2 各重训一次，共 9 次训练；
数值为三次重复的均值 ± 样本标准差。完整数据见
[`04_训练结果/seed_sweep/seed_sweep.md`](04_训练结果/seed_sweep/seed_sweep.md)。

| 模型 | mAP50 | mAP50-95 | 平均排名 | 变异系数 CV |
|---|---:|---:|---:|---:|
| YOLOv8s | 0.7559 ± 0.0137 | 0.4215 ± 0.0087 | 2.00 | 1.81% |
| YOLO11s | 0.7441 ± 0.0039 | 0.4302 ± 0.0033 | 3.00 | 0.52% |
| **YOLO26s** | **0.7646 ± 0.0094** | **0.4411 ± 0.0029** | **1.00** | 1.23% |

三次重复中名次完全一致（YOLO26s 第一、YOLOv8s 第二、YOLO11s 第三），说明模型差异
不是纯随机噪声。若只追求精度，应选 YOLO26s；实际部署仍选 YOLO11s，因为它的参数量
和权重体积最小、CPU 推理负担最轻，而 mAP50 只比 YOLO26s 低约 0.02。

### 鲁棒性压力测试

固定 seed 0 的三个权重，只对测试图像施加扰动，标注、输入尺寸和评估脚本不变：
5 类扰动 × 3 个严重度，共 16 组条件。完整数据、热力图和曲线见
[`04_训练结果/robustness/`](04_训练结果/robustness/)。

- 亮度变化影响最轻：最暗一档 mAP50 只下降 0.3%~5.5%。
- 低对比度、水平运动模糊和 JPEG 压缩在中高严重度下造成约 29%~42% 的下降。
- 高斯噪声最致命：严重度 1 就下降 38%~45%，严重度 3 下降超过 83%。
- YOLO11s 在运动模糊下退化最快（严重度 3 下降 42.0%），但在 JPEG 压缩下比
  YOLOv8s 稳（30.0% 对 39.7%）；YOLO26s 在多数条件下最好，高斯噪声下同样失效。
- 逐类看，噪声几乎摧毁夹杂、氧化铁皮压入和划痕的检测，斑块仍有 0.599；
  龟裂在所有扰动下都低于 0.35，与逐类结果一致。

已知短板：龟裂（crazing）各类 mAP50 只有 0.26~0.41。这类缺陷是细密网状微裂纹，
在 200×200 灰度图上与轧制纹理高度相似，是 NEU-DET 公认最难的一类。
