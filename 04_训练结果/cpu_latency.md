# CPU 推理延迟（YOLO26s 部署权重，对照）

测量日期：2026-11-28。系统默认用 GPU 推理，主结果见 `gpu_latency.md`；这份是同一个权重在 CPU 上的 1 轮测量，用来对照。

- 模型：`best.pt`（YOLO26s），imgsz=320，conf=0.25，NMS IoU=0.45，device=`cpu`
- 数据：NEU-DET `test`，预热 10 张，计时 100 张，`--seed 0`
- 环境：AMD Ryzen 9 8945H（16 逻辑核心），PyTorch 2.14.1+cu126，torch 线程 8，Ultralytics 8.4.202
- 权重加载：45.2 ms；首张冷启动：1666.2 ms

## 说明

- 计时为端到端 `model.predict`，含预处理、推理、NMS 和后处理；不含磁盘读取。
- 批量吞吐按“N 张一组调用 predict”统计，包含 Python 前后处理开销。
- 笔记本 CPU 受功耗和温度影响，重复运行会有几个百分点的波动。
- 原始数据：`cpu_latency.csv`（本文件）；`cpu_latency/yolo26s_r1.csv`（同一份）；
  `cpu_latency/yolo11s_cpu.csv` 是旧部署权重（YOLO11s）当时的测量，均值 26.90 ms。
